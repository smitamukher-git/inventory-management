System Architecture

Factory Inventory Management System

A full-stack demo combining a Vue 3 single-page frontend, a FastAPI service layer, and mock JSON datasets to simulate inventory, orders, demand, and spending workflows.

High-level architecture

User Browser Vue views, filters, charts, and modals
→
Frontend Vite + Vue 3 + Router + Axios
→
API Layer FastAPI on port 8001
→
Data Source In-memory JSON files in server/data

Technology stack

Frontend

  • Vue 3 Composition API
  • Vue Router for page navigation
  • Vite for local development
  • Axios for HTTP calls

Backend

  • Python FastAPI
  • Pydantic validation
  • CORS enabled for frontend access
  • REST-style endpoints

Data

  • JSON files in server/data
  • Loaded through server/mock_data.py
  • No database layer in demo mode
  • Filters applied in memory
Vue 3 Vite FastAPI Pydantic Axios JSON REST API

Data flow

1

UI filters

The user selects warehouse, category, status, and month filters from the Vue views and shared filter composables.

2

API client request

The frontend sends query parameters through client/src/api.js using Axios to the backend endpoints such as /api/orders and /api/dashboard/summary.

3

FastAPI processing

The backend applies filter logic, optional month logic, and Pydantic response models, then returns structured JSON for the Vue UI.

Vue filters → client/src/api.js → FastAPI → server/mock_data.py → JSON datasets → filtered response → computed UI metrics

Core application structure

Frontend folders

  • client/src/views - page-level screens
  • client/src/components - reusable UI parts
  • client/src/composables - shared filter state
  • client/src/api.js - backend communication

Backend folders

  • server/main.py - FastAPI app and endpoints
  • server/mock_data.py - JSON loader
  • server/data - inventory, orders, demand, and spending files

Main API areas

  • /api/inventory
  • /api/orders
  • /api/dashboard/summary
  • /api/spending/*
  • /api/demand and /api/backlog
